# Gale

### Beautiful Thunderstore mod manager

Gale is a modern, beautiful mod manager for Thunderstore games including Lethal Company, Risk of Rain 2, Valheim, and more. A faster, more polished alternative to r2modman built with a native UI framework.

<br>

---

## Features

| | |
|:---|:---|
| **Fast Downloads** | Parallel downloading makes installing large modpacks dramatically faster |
| **Beautiful UI** | Modern, polished interface that feels native on Windows and macOS |
| **Profile System** | Multiple mod profiles with easy switching and sharing via import codes |
| **Config Editor** | Edit mod configuration files directly inside the manager |
